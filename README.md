# SOFIA

**SOFIA** es una aventura narrativa 2D/2.5D sobre un padre que atraviesa un mundo simbólico formado por recuerdos, alegría, pena, culpa, distancia y esperanza, impulsado por la necesidad de reconectar con su hija Sofi. En el viaje lo acompaña Hele, su otra hija, representada como un destello amarillo vivo que actúa como guía, compañía y puente emocional.

## Visión

Crear una experiencia corta pero excepcionalmente pulida donde historia, jugabilidad, animación, arte y música formen un único lenguaje emocional. La referencia de calidad es el nivel de sensibilidad, composición y acabado de juegos poéticos como GRIS, pero SOFIA debe desarrollar identidad visual, personajes, escenarios y mecánicas propias.

## Pilares

1. **Emoción jugable** — las emociones se convierten en mecánicas.
2. **Arte pictórico premium** — cada frame debe poder sentirse como una ilustración.
3. **Animación excepcional** — movimiento expresivo, fluido, con peso y acting.
4. **Mecánicas con significado** — cada sistema debe aportar a la historia.
5. **Narrativa sutil** — contar principalmente mediante mundo, movimiento, música y símbolos.

## Tecnología prevista

- Unity 6
- Universal Render Pipeline (URP)
- Enfoque 2D/2.5D
- Cinemachine
- Input System
- Shader Graph
- 2D Animation
- Timeline
- Audio adaptativo con FMOD o Wwise por validar

## Primer objetivo

Construir el vertical slice **VS01 — El Primer Destello**, de 5 a 10 minutos, con calidad cercana al objetivo final.

Debe validar:
- movimiento y game feel;
- cámara;
- dirección de arte;
- Hele como compañera;
- primer puzle emocional;
- transición visual del mundo;
- aparición de Sofi;
- música reactiva;
- pipeline de animación;
- integración arte → motor.
