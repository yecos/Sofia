# SOFIA — Roadmap v0.1

## Fase 0 — Fundación

- repositorio;
- README;
- visión;
- GDD;
- historia;
- mecánicas;
- arte;
- animación;
- pipeline;
- roadmap;
- definición de vertical slice.

**Exit criteria:** el equipo entiende qué juego se está construyendo y qué no.

## Fase 1 — Visual Development

- diseño del padre;
- diseño de Sofi;
- diseño de Hele;
- arquitectura propia;
- color script;
- 3–5 key arts;
- pruebas de profundidad;
- pruebas de luz;
- prueba de escenario completo.

**Exit criteria:** una captura in-engine debe parecer inequívocamente SOFIA.

## Fase 2 — Prototype

- controller;
- cámara;
- salto;
- caída;
- Hele básica;
- interacción;
- memory trigger;
- primer cambio emocional del entorno;
- prototipo de música adaptativa.

**Exit criteria:** moverse durante 5 minutos ya debe sentirse agradable.

## Fase 3 — Vertical Slice VS01

- nivel 5–10 min;
- arte near-final;
- animación pulida;
- Hele funcional;
- puzzle;
- transición emocional;
- Sofi visible;
- audio;
- VFX;
- QA.

**Exit criteria:** pieza presentable externamente sin disculpas de “es solo prototipo”.

## Fase 4 — Producción por capítulos

Orden recomendado:
1. El silencio
2. Alegría
3. Pena
4. Distancia
5. Culpa
6. Hele
7. Esperanza
8. Sofía

Cada capítulo pasa por blockout → art → animation → audio → polish → QA.

## Fase 5 — Alpha

Juego completo de principio a fin.

## Fase 6 — Beta

Sin nuevas features. Solo:
- bugs;
- balance;
- accesibilidad;
- performance;
- polish.

## Fase 7 — Release Candidate

- builds;
- QA final;
- store assets;
- trailer;
- créditos;
- documentación.

## Regla de alcance

Si una feature amenaza el nivel de calidad visual o de animación, se reduce alcance antes de reducir polish.
